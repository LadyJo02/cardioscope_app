# CardioScope Dataset

The CardioScope dataset contains anonymized phonocardiogram (PCG) recordings
used for training and evaluating the deep learning models in this project.

## Access
The dataset is hosted externally due to size and ethical considerations:

https://drive.google.com/drive/folders/1w_TKrdESWz-XGh7LZr5CQdL1MFQ_aOaH

## Reproducibility
This repository includes the complete **data preprocessing, model training,
and evaluation pipelines** required to reproduce the reported experiments
using the provided dataset.

## Notes
- Data are anonymized and de-identified
- Intended for research and educational use only
- Not for clinical diagnosis or medical decision-making
